# 劉文軒｜6F 行動政見

以 Next.js、TypeScript、Tailwind CSS 與 shadcn/ui 組件結構製作的響應式候選人介紹網站。

## 本機啟動

```bash
npm install
npm run dev
```

開啟 `http://localhost:3000`。

## 驗證

```bash
npm run typecheck
npm run build
```

部署時可設定 `NEXT_PUBLIC_SITE_URL`，讓 Open Graph 圖片使用正式網域。
